Done safely

A wrong "recalled" can hurt an honest seller, and a wrong "fine" can hurt a family. These rules are in the code, not the prompt.

  • Code picks the answer. Plain rules turn the evidence into a colour; Gemini only explains it, in your language.
  • Exact model only. A look-alike never inherits a recall. A possible rebrand goes to a person.
  • "Can't tell yet" is an answer. When the evidence is thin, it says so instead of guessing.
  • No seller named as unsafe without a person checking the evidence. No reporter identities stored.
  • Translations are marked. Machine-translated replies say so, and fall back to English if translation fails.
