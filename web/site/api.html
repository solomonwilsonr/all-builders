How to read an answer.
Code picks the colour from the evidence; Gemini only explains it. Show the colour, then the reasons, then let people open the evidence behind each one.

      

        

          
The four answersverdict.overall, and safe and real on their own

          

            
    
              
  • red
    Don't buy
    An official recall of this exact model, or the listing is not real.
    • 
              
  • amber
    Be careful
    Buyer hazard reports under review, a recall abroad, or a safety mark that doesn't match the registry.
    • 
              
  • green
    No problems found
    In what was checked. Never a promise that a product is safe.
    • 
              
  • unknown
    Can't tell yet
    Not enough evidence. SafeShelf says so instead of guessing, and never shows grey as green.
    • 
            

            
Only an exact model match carries a recall. A look-alike's recall is never blamed on the wrong product.

Access, limits and errors.
The API is public so shoppers and judges can use it without signing up. Calls that use Gemini are rate-limited, so one caller can't use up the day for everyone.

      

        

          
Who can call whatSend keys in the X-API-Key header

          

            
AccessCovers

            
              
publicChecks, product records, recalls, sources, benchmarks. No key needed

              
reviewer keyDeciding findings, cases and identity labels. A person signs off every consequential call

              
developer keyCatalog scans, signed webhooks and your own usage (ssk_… tenant keys)

              
MCP and A2A/mcp and /a2a are open on the hosted demo (A2A is rate-limited); a self-hosted server can require X-API-Key. See For agents

            

        

        

          
Limits and status codesEvery refusal has CORS headers and a reason in detail

          

            
CodeWhen

            
              
200The answer. A partial outcome means a source was down; the answer says which

              
401Missing or wrong X-API-Key on a keyed route

              
413Body over 1 MB (9 MB for photo routes: chat, camera, incidents)

              
422The body doesn't match the contract; detail names the field

              
429Over 30 Gemini checks a minute per caller, or the daily cap. Honour Retry-After

            

            
Database reads (recalls, sources, timelines, benchmarks) don't count against the check limit. A listing checked in the last 10 minutes is answered from memory.

        

      

    


    

      
Investigations stream as they work.
POST /v1/agent/sessions/stream sends server-sent events, so your screen can show each step as it happens: page read, product matched, 12 countries' recall lists searched, reviews read, verdict.

      

        
openEVENT
The session started: its session_id and the plan of steps.

        
stepEVENT
One step finished: tool, what it found, time taken. Many per session.

        
verdictEVENT
The colours and reasons, as soon as code has decided them.

        
doneEVENT
The full result. Fetch every step's model, time and cost at /v1/investigations/{id}/trace.
