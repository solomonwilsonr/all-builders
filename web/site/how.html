How it works

Two questions: is it safe, and is it real?

Every check answers both, on one product-identity engine that recognises the same product under different brand names. The model writes the words; code decides the colour.

Four steps

From a product page to a sourced verdict.

Nothing leaves the page until you press Check. A typical check comes back in about 7 seconds, and the first colours arrive in about 3.

Read the page

The extension reads only the product area: title, model, price, photos, seller. Names, addresses, pincodes, emails and phone numbers are filtered out before anything is sent.

Find the exact product

The engine on Cloud Run matches the listing in a catalog of about 27,800 products, with Gemini on Vertex AI, and finds its rebranded twins.

Check records and signals

Official recalls and notices, buyer hazard reports, safety marks against the registry, copied photos, the price against the genuine product, and how old the shop is.

Set the verdict in code

Rules set red, amber, green or grey. Gemini then explains the result, and every sentence must cite an evidence id that exists. Thin evidence is grey, never green.

The identity rule

A look-alike's recall is not this product's recall.

Most false alarms come from matching the wrong product. SafeShelf sorts every match into one of three tiers before any recall is applied.

Exact model

Inherits the recall

Same model number, same maker. A recall of this model applies to this listing.

Possible rebrand

Goes to review

The same product sold under another brand name. Shown as "needs review", never as recalled, until a person checks it.

Look-alike

Never inherits

Similar photos or a similar name are not enough. A look-alike gets no safety claim at all.

Recalled abroad is not recalled here. A recall of the same model in another country is shown as "recalled abroad, same model", with the country and regulator named, so a shopper in India is never told a US recall is an Indian one.
