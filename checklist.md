# What Top Hackathon Winners Typically Do

This is a synthesis of patterns from winner write-ups, judge interviews, and post-mortems. It's not an official list from any one hackathon.

## 1. Before the event
- [ ] Study past winners of the same hackathon (Devpost galleries, demo videos)
- [ ] Read the rubric and sponsor goals, and design for them
- [ ] Prepare your stack in advance: starter repo, auth, deploy pipeline, API keys
- [ ] Form a team with complementary skills (builder, designer, storyteller)

## 2. Hour 0-3: Choose the idea
- [ ] Pick a real problem you can describe through one specific person
- [ ] Write a one-line pitch
- [ ] Validate it quickly with a mentor, judge, or someone outside your team
- [ ] Define the one "wow moment" and cut everything else

## 3. Hour 3-12: Build the skeleton
- [ ] Get a working end-to-end flow, however ugly
- [ ] Deploy it to a live URL early
- [ ] Integrate the sponsor's technology deeply, not superficially
- [ ] Use real data and real API calls for the core flow

## 4. Middle stretch: Strengthen
- [ ] Add one technically impressive element (an architecture choice, a hard problem solved)
- [ ] Polish the UI, name, and logo
- [ ] Test the failure cases the demo will hit
- [ ] Sync as a team every few hours

## 5. Final 20%: Freeze and package
- [ ] **Feature freeze**, then bug fixes only
- [ ] Record a backup demo video
- [ ] Write a strong README with screenshots and an architecture diagram
- [ ] Complete the submission page carefully
- [ ] Submit early

## 6. Pitch like a winner
- [ ] Open with the problem and a person, not the tech
- [ ] Demo live, and keep the video ready as a fallback
- [ ] Include one impact number
- [ ] Mention one technical highlight in a sentence
- [ ] Close with a believable "what's next"
- [ ] Rehearse at least twice with a timer
- [ ] Prepare for Q&A: "Why you?", "How does it scale?", "What's the hardest part?"

## 7. After submitting
- [ ] Share the project publicly (X, LinkedIn, community channels)
- [ ] Follow up with the judges and sponsors you spoke to
